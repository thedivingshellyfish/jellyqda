# Keyboard shortcuts

On the Mac use **Cmd** instead of **Ctrl**.

| Shortcut | Where | Effect |
|---|---|---|
| **Ctrl+1 … Ctrl+9** | text marked | 1st–9th code of the coding bar: codes directly or unfolds its subcodes |
| **1 … 9** | subcodes unfolded | assign the subcode |
| **0** | subcodes unfolded | assign only the code itself |
| **Esc** | subcodes unfolded | fold up |
| **Enter** | search field of the coding bar | assign the first hit; without a hit: create a new code and assign it |
| **F2** | code selected in the tree | rename |
| **Ctrl+S** | everywhere | save + restore point |
| **Ctrl+M** | text marked | passage memo (with text in the field: at once; otherwise the form) |
| **Ctrl+Z** | everywhere except text fields | undo |
| **Ctrl+Y** / **Ctrl+Shift+Z** | everywhere except text fields | redo |
| **Ctrl+Enter** | in the memo field | save memo |
| **Esc** | overlap list open / input field in the tree | close / cancel |

Note: some browsers use Ctrl+1…9 themselves to switch tabs; clicking the
codes and the search field always work.

## Mouse

| Action | Effect |
|---|---|
| mark text | coding bar: codes and subcodes, search, in vivo, as segment, memo |
| text marked + click on a code in the tree | code the marked text with this code |
| double click on a code in the tree | rename |
| arrow in front of a code | expand/collapse its subcodes |
| click on **"Seg N"** | mark the whole segment |
| click into the text | segment bar: split, merge |
| click on a coloured passage | show the coding, re-code, comment, delete |
| mouse over a grey place with a number | all codings of this place; a click pins the list |
| click on an underlined passage | show its memo |
| drag a code onto another code | make it a subcode |
| drag a code to the very bottom ("Drop here …") | top-level code again |
| drag a panel header | move the panel to another column |
| drop files on "Documents" | import |
