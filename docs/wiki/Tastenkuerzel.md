# Tastenkürzel

Auf dem Mac jeweils **Cmd** statt **Strg**.

| Kürzel | Wo | Wirkung |
|---|---|---|
| **Strg+1 … Strg+9** | Text markiert | 1.–9. Code der Kodier-Leiste: kodiert direkt oder klappt seine Subcodes aus |
| **1 … 9** | Subcodes ausgeklappt | Subcode vergeben |
| **0** | Subcodes ausgeklappt | nur den Code selbst vergeben |
| **Esc** | Subcodes ausgeklappt | zuklappen |
| **Enter** | Suchfeld der Kodier-Leiste | ersten Treffer vergeben; ohne Treffer: neuen Code anlegen und vergeben |
| **F2** | Code im Baum ausgewählt | umbenennen |
| **Strg+S** | überall | Speichern + Sicherungspunkt |
| **Strg+M** | Text markiert | Textstellen-Memo (mit Text im Feld: sofort; sonst Formular) |
| **Strg+Z** | überall außer Textfeldern | Rückgängig |
| **Strg+Y** / **Strg+Umschalt+Z** | überall außer Textfeldern | Wiederholen |
| **Strg+Enter** | im Memo-Feld | Memo speichern |
| **Esc** | Überlappungs-Liste offen / Eingabefeld im Baum | schließen / abbrechen |

## Maus

| Aktion | Wirkung |
|---|---|
| Text markieren | Kodier-Leiste: Codes und Subcodes, Suche, Als Segment, Memo |
| Text markiert + Klick auf Code im Baum | Markierung mit diesem Code kodieren |
| Doppelklick auf Code im Baum | umbenennen |
| Pfeil vor einem Code | Subcodes ein-/ausklappen |
| Klick auf **„Seg N“** | ganzes Segment markieren |
| Klick in den Text | Segment-Leiste: teilen, zusammenführen |
| Klick auf farbige Stelle | Coding anzeigen, umkodieren, löschen |
| Maus über graue Stelle mit Zahl | alle Codings dieser Stelle; Klick heftet fest |
| Klick auf unterstrichene Stelle | zugehöriges Memo anzeigen |
| Code auf anderen Code ziehen | Subcode daraus machen |
| Code ganz nach unten ziehen („Hierher ziehen …“) | wieder Code auf oberster Ebene |
| Panel-Kopfzeile ziehen | Panel in andere Spalte verschieben |
| Dateien auf „Dokumente“ ziehen | importieren |
