Entwurf v2: Codes, Subcodes und A4-Bericht

Klickbare Attrappe. Doppelklick auf einen Code benennt ihn um, das Papierkorb-Symbol löscht ihn (mit Rückfrage und Rückgängig). Satz im Text anklicken = markieren. Bei markiertem Text kodiert auch ein Klick in den Baum. Ein kodierter Satz lässt sich anklicken und umkodieren.

1+ Code und + Subcodeneu

„+ Code“ im Panelkopf legt einen Code auf oberster Ebene an, „+ Subcode“ an jeder Zeile einen darunter. Beides direkt im Baum: Name tippen, Enter. Das alte Formular entfällt.

2Umbenennen per Doppelklickneu

Doppelklick (oder F2) macht das Label zum Eingabefeld. Enter speichert, Esc bricht ab. Probier: „Motivation“ → „Motiv“.

3Löschen mit Rückfrageneu

Papierkorb an der Zeile. Die Rückfrage nennt, was mitgelöscht wird (Subcodes, Codings). Danach „Rückgängig“ im Hinweis und wie gewohnt Strg+Z.

4Kodier-Leiste

Codes als Chips, Klick klappt Subcodes am Faden aus, Suche über den Pfad. Beim Überfahren erscheint die Definition aus dem Code-Memo.

5Kodieren im Baum, Umkodierenneu

Mit markiertem Text ist auch jeder Baum-Eintrag ein Kodier-Knopf. Klick auf ein bestehendes Coding zeigt Codes derselben Familie zum Umkodieren, ohne Löschen und Neuanlegen.

6Code-Matrix gegliedertneu

Die Matrix folgt dem Baum: Codes zeigen die Summe mit Subcodes, die Gruppen klappen mit dem Baum mit ein und aus.

7Speichern

Status „Alles gespeichert“, Strg+S schreibt fest und legt einen Sicherungspunkt an.

8Bericht: A4, druckfertigneu

Öffnet im neuen Tab als A4-Seiten. Farben nur als Rahmen, Linien und Unterstreichungen, also auch ohne Hintergrundgrafiken druckbar. Tabelle mit Anteil in Prozent; Codes zählen ihre Subcodes mit.
