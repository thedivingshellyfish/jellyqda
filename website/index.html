Code your interviews in R. Fully offline, every step on record.

jellyqda is qualitative content analysis inside RStudio: import transcripts, build a code system, mark text and write memos. A project is one file on your computer, and every action can be undone.

> source("https://raw.githubusercontent.com/thedivingshellyfish/jellyqda/main/install_jellyqda.R")

One line in the R console installs jellyqda with all dependencies and tells you what to do next.

Get started Try the live demo Read the guide

The live demo runs online (shinyapps.io) with fictitious sample interviews – please don’t upload real interview data there. jellyqda itself works fully offline.

Made for qualitative research

Every function is explained with screenshots in the wiki and every R function in the reference.

Coding

  • Deductive and inductiveCoding guideline per code: definition, anchor example, coding rule. In-vivo codes, merging codes.
  • Overlaps made visiblePassages with several codings show a count; hover over it to see them all.
  • Auto-codingCode every hit of a search term in one step, undone with one Ctrl+Z.

Analysis

  • Mayring's summarising analysisParaphrase and generalisation per coding, exportable as CSV.
  • QueriesCodes combined with AND, OR and NOT, by group; save the hits as a code.
  • Case comparison, cases and summary gridCodes against document or case variables; one summary per code and document.
  • Four kinds of memosFor a passage, a document, a code and the whole project.

Data safety

  • Frozen textText is extracted once at import; tests check that what you see matches what is stored, character by character.
  • Automatic backupsRotating ZIP snapshots outside the project folder every 25 actions.
  • Pseudonymise while importingNames are replaced before the text is frozen; the key list stays with you.
  • German and EnglishInterface, help and report in both languages.

The same project, from a script

The app and the R functions write to the same file. Code a first pass in the app, then rerun your analysis from R Markdown or Quarto whenever the data changes.

All functions in the reference →

library(jellyqda)
qda_open("thesis.jellyqda")
qda_import("interview_01.docx")
qda_code_add("Career path")
qda_code(1, "Career path", segment = 3)

qda_stats()$overall       # share of material coded
qda_case_matrix(by = "group")
qda_export("report")       # A4 HTML report
qda_intercoder("coder_b.jellyqda") # kappa, alpha per code
qda_export_qdpx()              # for MAXQDA, ATLAS.ti, NVivo

Get started

You need R 4.0 or later, ideally with RStudio. Both are free.

Install once

About five minutes. The script checks the installation at the end.

source("https://raw.githubusercontent.com/thedivingshellyfish/jellyqda/main/install_jellyqda.R")

Create a project

Creates the project file, or reopens it next time.

library(jellyqda)
qda_open("my-analysis.jellyqda")

Start the app

Opens in your browser. Quit with Esc; everything is saved immediately.

qda_app()

Want to look around first? Try the live demo in your browser, no installation needed. No material yet? Try qda_import(system.file("extdata", "interview_01.txt", package = "jellyqda")). Offline machine? The release ZIP installs without internet.
