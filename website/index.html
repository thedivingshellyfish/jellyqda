Why jellyqda?

Because qualitative research should be privacy-friendly, traceable and free of licence fees, and because R is simply the best environment for that.

🔒

100 % offline, GDPR-friendly

No cloud, no uploads, no telemetry. All data stays in a local *.jellyqda file (SQLite). The app runs only on your own machine.

🧪

Data integrity taken seriously

Imported text is frozen at import, so codings never drift. Automated tests check that displayed and stored text are identical character by character.

🎓

Built for research

Every action with a timestamp in the audit trail, exportable for your methods section. And of course: citation("jellyqda") exists.

🆓

MIT licence, no costs

No subscription, no licence pressure, no lock-in. A proper R package with a complete API that also runs analyses reproducibly from scripts.

What's inside

Every function step by step with screenshots in the wiki, every R function in the API documentation.

📄

Import

.txt, .md, .docx, .pdf, via dialog or drag & drop. Text is frozen at import, so codings never drift.

🌳

Code tree with codes & subcodes

Every code family has its colour and hangs on a thread: collapse and expand, rename with a double click, code directly in the tree, merge codes including their subcodes.

🏷️

Coding with the mouse

Mark text, click a code chip, done. Subcodes unfold in the coding bar (Ctrl+1…9), re-code with one click, in-vivo codes straight from the marked text.

🔬

Deductive & inductive

A coding guideline per code: definition, anchor example (attached with one click) and coding rule, shown while coding, in the report and in the Word codebook. Plus: code all search hits at once.

🔀

Overlapping codings

Places with several codings are grey with a number and a coloured bar. Hover: a list of all codings with their comments, each shown or deleted individually.

✂️

Segments by speaker change

Segmentation by paragraphs, lines or speaker turns ([00:01:12] P: …), retroactively too. Split, merge, or define from highlights.

📝

Memos in four kinds

For a text passage, for the document (postscript), for a code (definition, coding rule) and for the project (research diary), plus a comment on every coding.

🧪

Mayring summarising analysis

Paraphrase and generalisation per coding, editable as a table and exportable as CSV for Excel, with its own section in the report.

📊

Analysis & case comparison

Code matrix with case comparison across document variables, summary grid, word frequencies without stop words, keyword in context (KWIC), full-text search, progress statistics.

🖨️

Report on A4

HTML report with frequencies in percent and a margin column next to each interview: codings, comments and memos exactly where they occur. Print-ready on A4.

↩️

Undo & redo

For everything, with a tooltip showing what will happen. The history survives even an app restart, and every action lands in the complete audit trail.

🌐

German & English

The whole interface, help, notifications and report in both languages, switchable with the DE/EN button or qda_app(lang = ...).

📤

Export & backups

CSV, Excel, Word codebook and HTML report. Rotating ZIP backups outside the project folder, automatically every 25 actions.

🧮

Scriptable & reproducible

Everything works via R code as well: every function returns a tibble. Ideal for reproducible analyses in your thesis.

Get started in 3 steps

You need R version 4.0 or later, ideally with RStudio. Both are free. One line is enough for the installation.

1

Install (once, about 5 minutes)

Paste this line into the R console. The script installs all required packages, then jellyqda, checks the installation and tells you how to continue at the end.

source("https://raw.githubusercontent.com/thedivingshellyfish/jellyqda/main/install_jellyqda.R")
2

Create a project

library(jellyqda)
qda_open("my-analysis.jellyqda")   # creates the project file (and reopens it later)
3

Start the app and start coding

qda_app()   # opens the app in the browser

Import transcripts on the left (or drag & drop them in), create your first codes in the code tree, then mark text in a transcript and click a code. Quit with Esc or the red X; everything is saved immediately after every action anyway.

💡 Try it without your own material: qda_import(system.file("extdata", "interview_01.txt", package = "jellyqda")) or the fictional transcripts in the demo/ folder of the repo.
🔌 Offline machine? The releases page has the release ZIP; the installation script installs from it without internet (the configuration lines for that are at the very top of the script).
