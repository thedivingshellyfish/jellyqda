# Demo files

> **Everything in this folder is fictional.** The interviews, persons
> (e.g. "Alex", "Bea", "Mara", "Jonas", "Selin"), the coders "anna" and "ben",
> companies, places and events are **invented** for trying out jellyqda. Any
> resemblance to real persons or organisations is coincidental. Every text
> file starts with a line that marks it as a demo file.

| File | What it is |
|---|---|
| `demo_interview_10min.txt` … `demo_interview_120min.txt` | four fictional transcripts of an invented study ("Working in small software companies"), about 10, 30, 60 and 120 minutes of talk, one line per speaker turn with time stamps (`[00:01:12] P: …`). Good for import, segments by speaker turns, coding, word frequencies, keyword in context. Generated by `data-raw/make_demo_transcripts.R`. |
| `intercoder/` | three short fictional interviews (Mara, Jonas, Selin) for the intercoder demo |
| `jellyqda-demo.R` | end-to-end demo with the example files of the package (`inst/extdata/`): import, code, segments, statistics, export, backup |
| `jellyqda-intercoder-demo.R` | intercoder agreement: blind copy, two coders, Cohen's kappa / Krippendorff's alpha, disagreements, consensus |
| `Screenshot_jellyqda_001.png` | a screenshot of the app |

Run the demos from the root of the source folder:

```r
pkgload::load_all(".")
source("demo/jellyqda-demo.R")
source("demo/jellyqda-intercoder-demo.R")
```

The short example files that ship with the package are in `inst/extdata/`
(see the README there); they are fictional as well.
